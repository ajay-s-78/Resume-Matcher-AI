WORKFLOW

How Resume Matcher Works

A four-step NLP pipeline transforming raw text into actionable career insights.

01

Upload Resume

Paste the candidate's technical resume or skills overview into the workspace.

02

Add Job Requirements

Input the target job description and key technical qualifications.

03

AI Semantic Matching

Sentence-Transformers convert both texts into dense vector embeddings and measure similarity.

04

Get Insights

View matched skills, missing skill gaps, and tailored career development feedback.

ARCHITECTURE

Powered by Modern NLP & AI

Built with industry-standard open-source machine learning frameworks.

🤖

Sentence Transformers

Uses Hugging Face's all-MiniLM-L6-v2 pre-trained BERT model to generate rich 384-dimensional semantic embeddings.

🔤

NLTK Preprocessing

Cleans, lowercases, tokenizes, and removes noise/stopwords from text inputs prior to vectorization.

📐

Cosine Similarity

Computes mathematical vector distances between candidate profile and job requirements to calculate accurate match percentages.

🔍

Skill Matcher Engine

Parses technical competencies against a curated dataset (`skills.csv`) to highlight matched and missing skills.

⚡

FastAPI Backend

High-performance asynchronous Python API with Pydantic validation, CORS middleware, and static file serving.
